# Adjective Order

Adjective order refers to the conventional sequence in which multiple adjectives are placed before a noun. Following this order helps sentences sound natural and clear in English.

## 1. General Order

The most common adjective order is:

**Opinion → Size → Age → Shape → Color → Origin → Material → Purpose → Noun**

Example:

- a beautiful small old round red Italian wooden dining table

Not every sentence contains all of these categories.

## 2. Opinion

Opinion adjectives express personal judgments or evaluations.

Examples:

- beautiful
- interesting
- amazing
- expensive
- boring
- wonderful

Examples:

- a beautiful painting
- an interesting book
- an expensive car

## 3. Size

Size adjectives describe how large or small something is.

Examples:

- big
- small
- large
- tiny
- tall
- short

Examples:

- a small table
- a large building
- a tall man

## 4. Age

Age adjectives describe how old or new something is.

Examples:

- old
- young
- new
- ancient
- modern

Examples:

- an old house
- a young child
- a modern building

## 5. Shape

Shape adjectives describe the form or shape of something.

Examples:

- round
- square
- rectangular
- triangular
- oval

Examples:

- a round table
- a square box
- a rectangular screen

## 6. Color

Color adjectives describe the color of the noun.

Examples:

- red
- blue
- green
- black
- white
- yellow

Examples:

- a red car
- a blue shirt
- a black computer

## 7. Origin

Origin adjectives indicate where something or someone comes from.

Examples:

- American
- Italian
- French
- Chinese
- Chilean
- Japanese

Examples:

- an Italian restaurant
- a Japanese car
- Chilean wine

## 8. Material

Material adjectives describe what something is made of.

Examples:

- wooden
- metal
- plastic
- glass
- cotton
- leather

Examples:

- a wooden chair
- a metal table
- a glass bottle

## 9. Purpose

Purpose adjectives describe what something is used for. They are often formed from nouns.

Examples:

- dining
- sleeping
- cooking
- writing
- sports

Examples:

- a dining table
- a writing desk
- a cooking pot
- a sports car

## 10. Complete Structure

The complete pattern is:

**Determiner + Opinion + Size + Age + Shape + Color + Origin + Material + Purpose + Noun**

Example:

- a beautiful small old round red Italian wooden dining table

Another example:

- an expensive large new rectangular black Japanese metal computer desk

## 11. Examples

### Example 1

- a beautiful small round Italian ceramic vase

Order:

- beautiful → Opinion
- small → Size
- round → Shape
- Italian → Origin
- ceramic → Material
- vase → Noun

### Example 2

- a small rectangular wooden coffee table

Order:

- small → Size
- rectangular → Shape
- wooden → Material
- coffee → Purpose
- table → Noun

### Example 3

- a stunning expensive diamond necklace

Order:

- stunning → Opinion
- expensive → Opinion
- diamond → Material
- necklace → Noun

### Example 4

- a big fluffy playful Labrador retriever

Order:

- big → Size
- fluffy → Quality/Description
- playful → Quality/Description
- Labrador → Origin/Type
- retriever → Noun

## 12. Important Note

The adjective order is a **general guideline**, not an absolute rule. Native speakers may change the order depending on context, emphasis, rhythm, or the specific meaning they want to communicate.

Also, adjectives from the same category can sometimes be connected with **and**.

Example:

- a tall, handsome, and intelligent man
- a long, elegant, and beautiful dress

## Quick Memory Rule

Remember:

**OSASCOMP**

- **O** → Opinion
- **S** → Size
- **A** → Age
- **S** → Shape
- **C** → Color
- **O** → Origin
- **M** → Material
- **P** → Purpose

**Opinion → Size → Age → Shape → Color → Origin → Material → Purpose → Noun**
